# 📌 PCD Assignment 1 - Operasi Aritmatika, Gerbang Logika, dan Geometri pada Pengolahan Citra Digital
## 📖 Deskripsi
Tugas ini merupakan bagian dari mata kuliah Pengolahan Citra Digital yang berfokus pada Operasi Aritmatika, Gerbang Logika, dan Transformasi Geometri dalam Citra Digital.

## 🎯 Tujuan
- Memahami konsep operasi artimatika pada Pengolahan Citra
- Memahami konsep gerbang logika pada Pengolahan Citra
- Memahami konsep operasi geometri pada Pengolahan Citra
